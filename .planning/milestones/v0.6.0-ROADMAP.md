# Milestone v0.6.0: Gantt Chart Zoom

**Status:** SHIPPED 2026-03-19
**Phases:** 19-21
**Total Plans:** 4

## Overview

Users can zoom into the Gantt timeline to inspect short sessions and focus on specific time ranges, with scroll-wheel and button controls. Zoom operates 1x–4x with cursor anchoring, resets on date navigation, and does not regress any existing interactions.

## Phases

## Milestone Summary

**Key Decisions:**
- Width-expansion model (not transform:scale) — percentage-based bars reflow correctly
- Zoom state in TimelinePage (not GanttChart) — survives data refreshes
- Wheel zoom instant, button zoom with 150ms CSS transition — no cursor-anchor drift
- Scrollbar hidden (scrollbar-width: none) — prevents page height shift
- Zoom controls below chart (not in toolbar) — per user request
- Branch always stored including defaults — detail panel always shows branch
- Tick density thresholds at 1.75/2.75/3.75x for 1h/30min/15min

**Issues Resolved:**
- 12a tick label clipping at left edge (padding-left + negative margin)
- NumberStepper parseInt truncating decimal values (changed to parseFloat)
- Branch display null for main/master sessions (now stored, skipped in label only)

**Issues Deferred:**
- None

**Technical Debt Incurred:**
- DEFAULT_BRANCHES set duplicated in GanttBar.vue and ticket-scorer.js (could be shared constant)
