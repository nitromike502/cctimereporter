## Tech Debt Summary

### Product / UX

1. **CHART-04 aggregate line:** No literal "all sessions" overlay on the Per Message chart. Substituted with the Session Totals bar chart toggle. Decide whether to backfill the literal feature or update REQUIREMENTS to match shipped UX.
2. **CHART-05 toggle wording:** "Cumulative" → "Session Totals". Semantic substitution.
3. **CHART-06 granularity:** Per-project visibility, not per-session. Sessions cannot be individually toggled within a project.

### Process

4. **VERIFICATION.md missing for Phases 33, 34, 35.** Verifier was enabled in `config.json` but skipped at phase completion. Phase 32 and Phase 36 both have VERIFICATION.md, so the gap is in the middle three phases. This audit retroactively verified them; future milestones should run `/gsd:verify-phase` after each `/gsd:execute-phase`.
5. **35-02-SUMMARY.md was backfilled 2026-05-09** from commits `edf0284` + `dba4fc2`, not written at phase completion (2026-04-10).

### Recommendation

The three CHART-* PARTIAL items are intentional UX evolutions documented in the 35-02 SUMMARY backfill. Two reasonable paths:

- **Accept as shipped:** Update REQUIREMENTS.md to match the implemented UX (rename CHART-04/05/06 to reflect Session Totals toggle, project-level filtering, etc.) and proceed to `/gsd:complete-milestone 1.1.0`.
- **Plan gap closure:** Run `/gsd:plan-milestone-gaps` to add literal-spec features (aggregate overlay line, per-session toggles).

Either is defensible; recommend **accept as shipped** unless a user has explicitly asked for the literal CHART-04 aggregate overlay or per-session toggles.
