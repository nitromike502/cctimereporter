## v0.6.0 Requirements

### Layout Restructure

- [x] **LYOT-01**: Project name column stays pinned on the left while the timeline canvas scrolls horizontally
- [x] **LYOT-02**: Time axis header stays aligned with the scrollable canvas
- [x] **LYOT-03**: Chart renders identically to current layout at 1x zoom (no visual regression)

### Zoom Controls

- [x] **ZOOM-01**: Scroll wheel over the chart zooms in/out (plain wheel, no Ctrl modifier)
- [x] **ZOOM-02**: Zoom anchors to cursor position (content under cursor stays in place)
- [x] **ZOOM-03**: +/- zoom buttons below the chart
- [x] **ZOOM-04**: Zoom range: 1x to 4x
- [x] **ZOOM-05**: Zoom resets to 1x on date navigation

### Zoom Polish

- [x] **ZPOL-01**: Zoom level indicator showing current level with "x" suffix
- [x] **ZPOL-02**: Smooth CSS transition during button zoom changes (wheel zoom instant)
- [x] **ZPOL-03**: Adaptive time axis tick density at higher zoom levels (15min at 4x)

### Interaction Integrity

- [x] **INTR-01**: Click-to-detail on session bars still works correctly after zoom/scroll
- [x] **INTR-02**: Existing session detail panel, messages modal, and edit modal unaffected by zoom
