# Milestone v0.8.0: Programmatic Data Access

**Status:** ✅ SHIPPED 2026-03-30
**Phases:** 28-31
**Total Plans:** 7

## Overview

Expose session data through a stdio MCP server and CLI subcommands so Claude agents and scripts can pull time and session data programmatically. Both surfaces are thin wrappers over a shared service layer extracted from existing route handlers.

## Phases

### Phase 28: Service Layer

**Goal**: Timeline query and import logic lives in `src/services/` modules callable by routes, CLI, and MCP — no behavior change for existing web UI
**Depends on**: Phase 27 (complete codebase baseline)
**Plans**: 1 plan

Plans:
- [x] 28-01: Extract service modules, shared utilities, and thin route wrappers

**Details:**
- Created `src/services/timeline.js` with `createTimelineService(db)` returning `getTimelineUI()` and `getTimelineReport()`
- Created `src/services/sessions.js` with `createSessionsService(db)` returning `getMessages()` and `updateSession()`
- Created `src/services/import.js` with `runImport()` and `ImportConflictError`
- Extracted shared utils to `src/utils/timeline-utils.js`
- All route handlers thinned to HTTP-only wrappers

### Phase 29: Multi-Instance Coordination

**Goal**: Multiple processes share one SQLite database safely — only one web server and one import at a time, with automatic stale-process recovery
**Depends on**: Phase 28
**Plans**: 2 plans

Plans:
- [x] 29-01: Schema migration v8→v9, coordination service, DB-based import lock
- [x] 29-02: Server ownership claim and conflict detection in CLI

**Details:**
- `process_locks` table (schema v9) with PID, source, port, started_at
- `claimLock`/`releaseLock`/`isProcessAlive` coordination service
- `PRAGMA busy_timeout = 5000` for concurrent WAL access
- Import lock with source tracking ('web', 'cli', 'mcp')
- Server lock claimed after `fastify.listen()`, released on SIGINT/SIGTERM
- Stale PID detection auto-reclaims dead locks

### Phase 30: CLI Subcommands

**Goal**: Users and scripts can call `summary`, `sessions`, and `import` from the terminal with JSON output
**Depends on**: Phase 28, Phase 29
**Plans**: 2 plans

Plans:
- [x] 30-01: Format utility and command handler modules (summary, sessions, import)
- [x] 30-02: Commander integration in bin/cli.js and package.json updates

**Details:**
- Commander.js v14 dispatch with `serve` as default command
- `summary --date --pretty --idle` → JSON day summary to stdout
- `sessions --date --pretty --idle` → JSON session list to stdout
- `import --days --all --pretty` → stderr progress, stdout JSON result
- Exit codes: 0 success, 1 error, 2 import conflict
- CLI startup ~70ms (Fastify never loaded for non-serve commands)

### Phase 31: MCP Server

**Goal**: `npx cctimereporter --mcp` starts a stdio MCP server with 8 tools usable by Claude agents
**Depends on**: Phase 28, Phase 29, Phase 30
**Plans**: 2 plans

Plans:
- [x] 31-01: MCP server scaffold with 4 query tools (get_day_summary, get_sessions, get_session_messages, get_dates)
- [x] 31-02: 4 action tools (trigger_import, start_server, stop_server, server_status)

**Details:**
- @modelcontextprotocol/sdk 1.28.0 with StdioServerTransport

- 4 action tools: trigger_import, start_server, stop_server, server_status
- start_server launches inline Fastify with port fallback

## Milestone Summary

**Key Decisions:**
- Stdio MCP transport (not HTTP) — standard for npx-launched MCP servers
- Service layer extraction before CLI/MCP — isolated refactor for regression safety
- CLI before MCP — validates services with zero new dependencies first
- Factory pattern for DB-bound services, standalone function for import
- DB-based coordination over file locks — atomic, ACID, already have SQLite
- Commander.js for CLI dispatch with serve as default (backward compat)

**Issues Resolved:**
- Invalid date crashes in CLI (added YYYY-MM-DD validation)
- SQLite experimental warning on stderr (suppressed via removeAllListeners)
- UTC vs local date default in CLI (fixed to local)
- Import progress phase name mismatch ('discovering'/'importing')

**Issues Deferred:**
- Schema migration banner stuck after reimport (needs local testing)
- Empty fork sessions with 0 minutes still visible (filter threshold)
- Agent Teams subagent reporting (complex orchestrator patterns)

**Technical Debt Incurred:**
- start_server TOCTOU race: claimLock return not checked after listen() — orphaned Fastify possible
- maxAgeDays defaults inconsistent: web API 30 days, CLI/MCP 2 days
