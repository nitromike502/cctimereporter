1. Inside the `.action()` handler, after the existing `createTimelineService` lazy import, add a lazy import for the token service:
   ```javascript

   const tokenSvc = createTokensService(db);
   ```

2. After the existing `const report = svc.getTimelineReport(...)` line, fetch per-session token data:
   ```javascript
   const tokenData = tokenSvc.getDayTokens(date);
   const sessionTokenMap = new Map(tokenData.sessions.map(s => [s.sessionId, s]));
   ```

3. In the `enrichedSessions` mapping (where `.map(s => ({ ...s, workingTime: ... }))` currently runs), add a `tokens` field to each session:
   ```javascript
   const enrichedSessions = allSessions
     .map(s => {
       const sessionTokens = sessionTokenMap.get(s.sessionId);
       return {
         ...s,
         workingTime: formatWorkingTime(s.workingTimeMs),
         tokens: sessionTokens ? {
           inputTokens: sessionTokens.inputTokens,
           outputTokens: sessionTokens.outputTokens,
           cacheCreationInputTokens: sessionTokens.cacheCreationInputTokens,
           cacheReadInputTokens: sessionTokens.cacheReadInputTokens,
           totalTokens: sessionTokens.totalTokens,
           cacheHitRate: sessionTokens.cacheHitRate,
         } : null,
       };
     })
     .sort((a, b) => (a.startTime < b.startTime ? -1 : a.startTime > b.startTime ? 1 : 0));

   ```
   But strip the `sessionId` field from the tokens object since it's redundant (already on the session). Verify the actual return shape from the service.

4. Also fix the pre-existing code smell: remove the duplicate `const { outputJSON } = await import('../format.js');` on line 25 — it shadows the top-level import on line 9. Use the top-level `outputJSON` import. (The `formatWorkingTime` import is already top-level.)
