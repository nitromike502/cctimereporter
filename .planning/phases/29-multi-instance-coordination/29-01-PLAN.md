<task type="auto">
  <name>Task 2: Coordination service</name>
  <files>src/services/coordination.js</files>
  <action>
Create `src/services/coordination.js` with these exports:

1. `isProcessAlive(pid)` — returns boolean. Uses `process.kill(pid, 0)` in try/catch. Returns true if signal succeeds, false on any error (ESRCH = dead process).

2. `claimLock(db, lockName, pid, source, port = null)` — returns `{ claimed: boolean, owner?: object }`.
   - SELECT existing row from process_locks WHERE lock_name = ?
   - If exists and `isProcessAlive(existing.pid)` is true: return `{ claimed: false, owner: existing }`
   - If exists and PID is dead: DELETE WHERE lock_name = ? AND pid = ? (the AND pid guard prevents TOCTOU race — if another process already reclaimed, this DELETE affects 0 rows)
   - INSERT INTO process_locks (lock_name, pid, source, port) VALUES (?, ?, ?, ?)
   - Wrap INSERT in try/catch: if UNIQUE constraint error (race with another claimer), re-SELECT and return `{ claimed: false, owner: winner }`
   - On success: return `{ claimed: true }`

3. `releaseLock(db, lockName, pid)` — void. DELETE WHERE lock_name = ? AND pid = ? (only releases own lock).

4. `formatLockElapsed(startedAt)` — returns string like "2m 15s ago" or "45s ago".
   - Parse startedAt as UTC: `new Date(startedAt + 'Z').getTime()` (datetime('now') returns UTC without 'Z' suffix)
   - Compute elapsed seconds, format as Xm Ys ago or Xs ago

Use named exports (ESM). No default export. No classes — plain functions.
Do NOT use prepared statement caching (no `db.prepare()` stored in module scope) — the db handle is passed per-call.
  </action>
  <verify>
Run `node -e "
const { openDatabase } = await import('./src/db/index.js');
const { claimLock, releaseLock, isProcessAlive } = await import('./src/services/coordination.js');
const { db } = openDatabase();

// Test isProcessAlive
console.log('own pid alive:', isProcessAlive(process.pid));
console.log('dead pid alive:', isProcessAlive(99999));

// Test claim fresh lock
const r1 = claimLock(db, 'test', process.pid, 'web', 3847);
console.log('claim fresh:', r1);

// Test claim conflict (same lock, same pid is alive)
const r2 = claimLock(db, 'test', process.pid + 1, 'cli');
console.log('claim conflict:', r2);

// Release and re-claim
releaseLock(db, 'test', process.pid);
const r3 = claimLock(db, 'test', process.pid, 'mcp');
console.log('claim after release:', r3);

// Cleanup
releaseLock(db, 'test', process.pid);
db.close();
"` — should show own pid alive: true, dead pid alive: false, claim fresh: { claimed: true }, claim conflict with owner info, claim after release: { claimed: true }.
  </verify>
  <done>Coordination service exports claimLock, releaseLock, isProcessAlive, formatLockElapsed. Fresh claims succeed, live PID conflicts are detected, stale locks are reclaimed, releases only affect own PID.</done>
</task>
