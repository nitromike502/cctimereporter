Create `src/cli/format.js` with three exports:

1. `formatWorkingTime(ms)` -- converts milliseconds to human-readable string:
   - 0ms -> "0m"
   - ms < 60000 (under 1 min) -> "0m" (floor to minutes)
   - hours=0 -> "{mins}m"
   - mins=0 -> "{hours}h"
   - otherwise -> "{hours}h {mins}m"

2. `enrichWithFormattedTime(report)` -- walks a getTimelineReport() result and adds `workingTime` string alongside every `workingTimeMs` field. Must handle:
   - `report.workingTimeMs` (top-level)
   - `report.byTicket[].workingTimeMs` (per ticket group)
   - `report.byTicket[].sessions[].workingTimeMs` (per session in ticket)
   - `report.unticketedSessions[].workingTimeMs` (unticketed sessions)
   Returns a new object (spread, don't mutate).

3. `outputJSON(data, pretty)` -- writes `JSON.stringify(data, null, pretty ? 2 : undefined) + '\n'` to process.stdout.

Create `src/cli/commands/summary.js` exporting `summaryCommand(db)` that returns a Commander Command:

```javascript
import { Command } from 'commander';
```

- Command name: 'summary'
- Description: 'Print JSON day summary to stdout'
- Options: `--date <YYYY-MM-DD>` (default: today), `--pretty` (pretty-print JSON), `--idle <minutes>` (idle threshold, default '10')
- Action handler (async):
  1. `const { createTimelineService } = await import('../../services/timeline.js');`
  2. Create service: `const svc = createTimelineService(db);`
  3. Compute date: `options.date ?? new Date().toISOString().slice(0, 10)`
  4. Parse idle: `const idleThresholdMin = parseInt(options.idle, 10);`
  5. Call: `const report = svc.getTimelineReport(date, { thresholdMin: idleThresholdMin });`
     IMPORTANT: getTimelineReport takes an options object `{ thresholdMin }` as second arg, NOT a bare integer.
  6. Enrich: `const enriched = enrichWithFormattedTime(report);`
  7. Output: `outputJSON(enriched, options.pretty);`
  Use dynamic import for services inside action handler (not top-level) so module loading is deferred until command actually runs.

Create `src/cli/commands/sessions.js` exporting `sessionsCommand(db)` that returns a Commander Command:

- Command name: 'sessions'
- Description: 'Print JSON session list to stdout'
- Options: `--date <YYYY-MM-DD>` (default: today), `--pretty`, `--idle <minutes>` (default '10')
- Action handler (async):

Create `src/cli/commands/import.js` exporting `importCommand(db)` that returns a Commander Command:

- Command name: 'import'
- Description: 'Import Claude Code session transcripts'
- Options: `--days <N>` (import window in days, default '2'), `--all` (import all history, overrides --days), `--pretty` (pretty-print JSON result)
- Action handler (async):
  1. Dynamic import: `const { runImport, ImportConflictError } = await import('../../services/import.js');`
  2. Dynamic import: `const { outputJSON } = await import('../format.js');`
  3. Compute maxAgeDays: `options.all ? undefined : parseInt(options.days, 10)`
  4. Create onProgress callback that writes to stderr:
     - Check `process.stderr.isTTY` to decide separator (`\r` for TTY, `\n` otherwise)
     - Format: `Importing: ${processed}/${total}...` followed by separator
     - On final call (processed === total), write a newline to stderr if TTY (to clear the \r line)
  5. Wrap runImport in try/catch:
     - Success: `outputJSON(result, options.pretty)` and `process.exitCode = 0`
     - ImportConflictError: write message to stderr, `process.exitCode = 2`
     - Other error: write `Import failed: ${err.message}` to stderr, `process.exitCode = 1`
  6. Pass source as 'cli': `runImport(db, { maxAgeDays, source: 'cli', onProgress })`

Important: The onProgress callback receives `{ phase, processed, total, currentFile }`. Only show the counter during 'import' phase (not 'discovery' phase). During discovery phase, write `Discovering files...\n` to stderr once.
