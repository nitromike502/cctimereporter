<task type="auto">
  <name>Task 2: Bar click guard to prevent false selection after scroll</name>
  <files>src/client/components/GanttChart.vue</files>
  <action>
    When the user scrolls the zoomed chart by clicking and dragging (or via scrollbar), releasing the mouse can fire a click event on a bar. This causes unintended session selection (Pitfall 4).

    In GanttChart.vue, add a scroll-movement guard:

    1. Track whether meaningful scrolling occurred:
       ```javascript
       let scrollStartX = 0
       let didScroll = false

       function onScrollAreaMouseDown(event) {
         scrollStartX = scrollAreaEl.value?.scrollLeft ?? 0
         didScroll = false
       }

       function onScrollAreaScroll() {
         const currentX = scrollAreaEl.value?.scrollLeft ?? 0
         if (Math.abs(currentX - scrollStartX) > 5) {
           didScroll = true
         }
       }
       ```

    2. Wrap the select emit to check the guard:
       Replace the direct emit in the template. Change:
       ```
       @select="emit('select', $event)"
       ```
       to:
       ```
       @select="onBarSelect($event)"
       ```

       Add handler:
       ```javascript
       function onBarSelect(session) {
         if (didScroll) {
           didScroll = false
           return
         }
         emit('select', session)
       }
       ```

    3. Attach mousedown and scroll listeners to the scroll area in the template:
       ```html
       <div class="gantt-scroll-area" ref="scrollAreaEl"
            @mousedown="onScrollAreaMouseDown"
            @scroll="onScrollAreaScroll">
       ```

    This approach is lightweight: it only suppresses the click if scrollLeft changed by more than 5px between mousedown and click. Normal clicks (no scroll) pass through unaffected.
  </action>
  <verify>
    Run `npm run build` — build succeeds.
    Manual: Zoom to 2x+, scroll the chart by dragging or scrollbar, release — no session should accidentally get selected. Click a bar without scrolling — it should select normally.
  </verify>
  <done>Bar clicks after scroll-dragging are suppressed (5px threshold). Normal clicks without scrolling work as before. No regression in click-to-select at any zoom level.</done>
