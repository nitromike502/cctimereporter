**Day boundary helper** (same logic as timeline.js):
```javascript
function dayBoundaries(date) {
  return {
    dayStartUTC: new Date(date + 'T00:00:00').toISOString(),
    dayEndUTC:   new Date(date + 'T23:59:59.999').toISOString(),
  };
}
```

**Three prepared statements:**

1. `dayTotalStmt` - Aggregate all token columns for a date range, filtering `type='assistant' AND is_sidechain=0 AND is_fork_branch=0`. Use `SUM(col)` for individual breakdown columns (returns NULL naturally for no-data). Use `SUM(COALESCE(col, 0) + ...)` for `total_tokens` to avoid NULL propagation in arithmetic.

2. `perSessionStmt` - Same query but `GROUP BY m.session_id`. JOIN sessions table for the date filter to match sessions overlapping the day.

3. `singleSessionStmt` - Same aggregation for a single `session_id` (no date filter, no sessions JOIN needed). This is for future use by Phase 34/35 and the `/api/tokens/:sessionId` possibility.

**All three queries MUST include:**
- `WHERE m.type = 'assistant'`
- `AND m.is_sidechain = 0`
- `AND m.is_fork_branch = 0`

**Cache hit rate computation** in JS (not SQL):
```javascript
function computeCacheHitRate(cacheRead, input) {
  const denom = (cacheRead ?? 0) + (input ?? 0);
  if (denom === 0) return null;
  return Math.round(((cacheRead ?? 0) / denom) * 1000) / 10;
}
```
Returns one decimal precision. Returns `null` when no data (avoids NaN).

**`enrichRow(row)` helper** to convert snake_case SQL columns to camelCase JSON:
- `row.input_tokens` -> `inputTokens`
- `row.output_tokens` -> `outputTokens`
- `row.cache_creation_input_tokens` -> `cacheCreationInputTokens`
- `row.cache_read_input_tokens` -> `cacheReadInputTokens`
- `row.total_tokens` -> `totalTokens`
- Add computed `cacheHitRate` via `computeCacheHitRate(row.cache_read_input_tokens, row.input_tokens)`

**Create `src/server/routes/tokens.js`:**

Follow the exact thin-wrapper pattern from `src/server/routes/timeline.js`:

```javascript
import { createTokensService } from '../../services/tokens.js';

const DATE_RE = /^\d{4}-\d{2}-\d{2}$/;

function getTodayString() {
  const now = new Date();
  return `${now.getFullYear()}-${String(now.getMonth() + 1).padStart(2, '0')}-${String(now.getDate()).padStart(2, '0')}`;
}

export async function tokensRoute(fastify, opts) {
  const { db } = opts;
  const svc = createTokensService(db);

  fastify.get('/api/tokens', async (request, reply) => {
    const date = request.query.date ?? getTodayString();
    if (!DATE_RE.test(date)) {
      reply.code(400);
      return { error: 'Invalid date format. Use YYYY-MM-DD.' };
    }
    return svc.getDayTokens(date);
  });
}
```
