**Add fetchTokens function** (alongside existing `fetchTimeline`):
```javascript
async function fetchTokens() {
  try {
    const res = await fetch(`/api/tokens?date=${selectedDate.value}`)
    if (!res.ok) return // fail silently — tokens are supplementary
    tokenData.value = await res.json()
  } catch {
    // Token fetch failure should not affect timeline
    tokenData.value = null
  }
}
```

IMPORTANT: Token fetch is independent of timeline fetch. If it fails or is slow, the timeline still works. Do NOT make timeline loading wait for tokens.

**Add computed for selected session's tokens:**
```javascript
const selectedSessionTokens = computed(() => {
  if (!tokenData.value?.sessions) return null
  const sessionId = (selectedSession.value ?? selectedForkParentSession.value)?.sessionId
  if (!sessionId) return null
  return tokenData.value.sessions.find(s => s.sessionId === sessionId) ?? null
})
```

**Wire fetchTokens into lifecycle:**
- In `onMounted`: call `fetchTokens()` alongside `fetchTimeline()` (parallel, not awaited sequentially)
- In the `watch(() => route.query.date, ...)` watcher: call `fetchTokens()` alongside `fetchTimeline()`

**Update SessionDetailPanel usage** (in the template):

**Update DaySummary usage** (in the template):

function formatTokenCount(n) {
  if (n == null || n === 0) return '\u2014'  // em dash

}
