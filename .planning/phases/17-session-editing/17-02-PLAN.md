  1. Create `src/client/components/SessionEditModal.vue` following the Reka UI Dialog pattern from SessionMessagesModal.vue:

     **Props:** `open` (Boolean), `session` (Object — the full session object from timeline API)
     **Emits:** `update:open`, `saved` (with payload `{ userLabel, userTicket }`)

     **Template structure (stacked form layout):**
     - DialogRoot/Portal/Overlay/Content/Title/Description (same pattern as SessionMessagesModal)
     - Title: "Edit Session"
     - Close button (top right, same &times; pattern)
     - Form with @submit.prevent="save":
       - **Session Name field:**
         - `<label for="edit-name">Session Name</label>`
         - Input wrapper div containing:
           - `<input id="edit-name" v-model="nameValue" :disabled="nameReadOnly" :placeholder="namePlaceholder" type="text" />`
           - Clear button (x) visible when nameValue is non-empty AND not nameReadOnly: `@click="nameValue = ''"`
         - Below the field, if nameReadOnly: `<span class="field-note">Named in Claude Code</span>`
       - **Ticket ID field:**
         - `<label for="edit-ticket">Ticket ID</label>`
         - Input wrapper div containing:
           - `<input id="edit-ticket" v-model="ticketValue" :placeholder="ticketPlaceholder" type="text" />`
           - Clear button (x) visible when ticketValue is non-empty: `@click="ticketValue = ''"`
       - **Persistence notice** (below form fields):
         - `<p class="persistence-notice">Changes are local to CC Time Reporter and do not persist to Claude Code.</p>`
       - **CLI command block:**
         - `<div class="cli-command"><code>claude --session-id {{ session?.sessionId }}</code><button type="button" @click="copyCommand" class="copy-btn">{{ copied ? 'Copied!' : 'Copy' }}</button></div>`
       - **Save button:** `<button type="submit" class="save-btn">Save</button>`

     **Script setup logic:**
     - `nameValue` ref: initialized from `props.session?.userLabel ?? ''` when modal opens (watch open+session)
     - `ticketValue` ref: initialized from `props.session?.userTicket ?? ''` when modal opens
     - `copied` ref: for copy button feedback, reset after 2 seconds via setTimeout
     - `nameReadOnly` computed: `props.session?.summary && !props.session?.userLabel` — read-only when Claude Code named it AND user hasn't set a custom name. If user previously set userLabel, they can always edit/clear it.
     - `namePlaceholder` computed: shows the auto-detected name fallback — `props.session?.customTitle || props.session?.ticket || props.session?.branch || 'Session name'`
     - `ticketPlaceholder` computed: `props.session?.ticket || 'e.g. PROJ-123'`
     - `copyCommand` function: uses `navigator.clipboard.writeText()` with textarea fallback for non-HTTPS (see RESEARCH.md)
     - `save` async function:
       ```
       const res = await fetch(`/api/sessions/${encodeURIComponent(props.session.sessionId)}`, {
         method: 'PATCH',
         headers: { 'Content-Type': 'application/json' },
         body: JSON.stringify({
           userLabel: nameValue.value || null,
           userTicket: ticketValue.value || null,
         }),
       });
       if (!res.ok) throw new Error(`HTTP ${res.status}`);
       emit('saved', { userLabel: nameValue.value || null, userTicket: ticketValue.value || null });
       emit('update:open', false);
       ```
     - Watch `[() => props.open, () => props.session]`: when modal opens, reset nameValue and ticketValue from session props

     **Styles:** Follow modal-overlay, modal-content, modal-title, modal-close patterns from SessionMessagesModal. Use `width: min(480px, 90vw)` (narrower than messages modal since it's a form). Add styles for:

     - `.form-field input` — full width, padded, border, border-radius, bg-secondary background, uses design tokens

     - `.cli-command` — flex row, code block with monospace font, bg-secondary, border, rounded, copy button aligned right
     - `.copy-btn` — small button, border, rounded
     - `.save-btn` — primary colored button, full width, padded

       ```
       />
       ```
     - Add `onSessionEdited` handler for optimistic UI update:
       ```
       function onSessionEdited({ userLabel, userTicket }) {
         if (selectedSession.value) {
           selectedSession.value = {
             ...selectedSession.value,
             userLabel,
             userTicket,
           }
           // Also update the session in timelineData so GanttBar and DaySummary reflect changes
           if (timelineData.value) {
             for (const project of timelineData.value.projects) {
               const session = project.sessions.find(s => s.sessionId === selectedSession.value.sessionId)
               if (session) {
                 session.userLabel = userLabel
                 session.userTicket = userTicket
                 break
               }
             }
           }
         }
       }
       ```
     - This optimistic update avoids a full timeline refetch which would reset scroll position and selection.
