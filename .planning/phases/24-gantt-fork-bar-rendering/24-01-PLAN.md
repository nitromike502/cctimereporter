# Phase 24 Plan 01: Gantt Fork Bar Rendering

## Objective

Render fork branch segments as 50%-height sub-bars beneath their parent session bar in the Gantt chart, using a new GanttForkBar component. No row height or layout changes.

## Context Files

- @src/client/components/GanttSwimlane.vue — where fork bars render
- @src/client/components/GanttBar.vue — reference for positioning math
- @src/client/pages/ComponentsPage.vue — preview page registration

## Tasks

### Task 1: Create GanttForkBar.vue
`type="auto"`

Create `src/client/components/GanttForkBar.vue`.

Props:
- `fork` — Object with `{ forkBranchId, startTime, endTime, messageCount }`
- `date` — YYYY-MM-DD string for time-to-percent conversion
- `color` — Project color hex string (same as parent session)

Behavior:
- Position absolutely using same `timeToPercent()` math as GanttBar
- Height: 14px (50% of 28px)
- Visually distinct: lighter version using 50% opacity of the project color
- Show a tooltip-style title with branch ID and message count
- No click handler yet (Phase 25)

**Done:** File exists, component renders a positioned absolute div with correct left/width/height/color

---

### Task 2: Integrate GanttForkBar into GanttSwimlane
`type="auto"`

Modify `src/client/components/GanttSwimlane.vue`:

1. Import GanttForkBar
2. For each session bar rendered, also render any `session.forkSegments` entries as GanttForkBar components
3. Fork bars are positioned at: `top = rowIdx * BAR_ROW_HEIGHT + (28 - 14)` = rowIdx * 36 + 14px
   (14px from top of row = just below the 28px main bar, within the 36px row height)
4. Fork bars must NOT render if `session.forkSegments` is absent or empty (guard with `v-if` or null check)

**Done:** Sessions with forkSegments show sub-bars; sessions without forkSegments unchanged

---

### Task 3: Add GanttForkBar to ComponentsPage preview
`type="auto"`

Add GanttForkBar to `src/client/pages/ComponentsPage.vue`:

1. Import GanttForkBar
2. Add `{ id: 'gantt-fork-bar', label: 'GanttForkBar' }` to the components array
3. Add a showcase section with:
   - A relative-positioned container (height 50px, dark bg similar to a Gantt row)
   - Two example GanttForkBar instances side by side at different time offsets
   - Use a hardcoded `date` of `'2026-03-22'` and example fork objects with ISO timestamps

**Done:** GanttForkBar appears in sidebar and renders in the preview area
