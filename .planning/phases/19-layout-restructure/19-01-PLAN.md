Extract the subRows computation into a helper function or replicate the logic in a computed property that maps projects to their lane heights. The simplest approach: compute subRows count per project in GanttChart and use it for label row heights.

2. KEEP `.gantt-chart` CLASS on outermost div (driver.js tour targets it via `.gantt-chart` selector — see Pitfall 11 from research).

3. REMOVE `overflow: hidden` from `.gantt-chart` — this is the critical change that unblocks scrolling (Pitfall 3).

4. REMOVE `margin-left: 140px` from `.time-axis` — it is now inside the scroll area, not offset from labels.

8. The `.gantt-scroll-area` needs `min-width: 0` to prevent flex children from overflowing (standard flex layout fix).

9. Keep `padding-right: 10px` on `.gantt-scroll-area` (not on `.gantt-chart`) to maintain right-side spacing.

10. The `.lane-row` class is no longer needed (labels and bars are in separate columns). Each project in the scroll area is just a div wrapping GanttSwimlane.
