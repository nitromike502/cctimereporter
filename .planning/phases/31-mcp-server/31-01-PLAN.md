**Create `src/mcp/tools/query.js`:**

Export `function registerQueryTools(server, db)` that registers 4 tools using `server.registerTool()`.

**Import:**
- `z` from `zod`
- `createTimelineService` from `../../services/timeline.js`
- `createSessionsService` from `../../services/sessions.js`
- `enrichWithFormattedTime` from `../../cli/format.js`

**Create service instances at registration time** (not per-call):
```javascript
const timeline = createTimelineService(db);
const sessions = createSessionsService(db);
```

**Tool 1: get_day_summary**
- inputSchema: `{ date: z.string().regex(/^\d{4}-\d{2}-\d{2}$/).describe('Date in YYYY-MM-DD format'), idle_threshold_min: z.number().int().min(1).max(120).optional().describe('Idle gap threshold in minutes (default: 10)') }`
- Handler: Call `timeline.getTimelineReport(date, { thresholdMin: idle_threshold_min ?? 10 })`, then `enrichWithFormattedTime(report)`, return as JSON text content
- Description: "Get ticket-grouped working time summary for a date. Returns per-ticket working time totals and session counts."

**Tool 2: get_sessions**
- inputSchema: `{ date: z.string().regex(/^\d{4}-\d{2}-\d{2}$/).describe('Date in YYYY-MM-DD format'), idle_threshold_min: z.number().int().min(1).max(120).optional().describe('Idle gap threshold in minutes (default: 10)') }`
- Handler: Call `timeline.getTimelineUI(date, { thresholdMin: idle_threshold_min ?? 10 })` to get full session details. Return the `projects` array as JSON text content. This gives the agent per-session detail (start/end times, ticket, branch, summary, working time).
- Description: "Get all sessions for a date grouped by project. Returns detailed session info including start/end times, tickets, branches, summaries, and working time."

**Tool 3: get_session_messages**
- inputSchema: `{ session_id: z.string().describe('Session ID (UUID)'), fork_branch_id: z.string().optional().describe('Fork branch ID to filter messages (omit for primary branch)') }`
- Handler: Call `sessions.getMessages(session_id, { forkBranchId: fork_branch_id })`. If result is null, return `{ isError: true, content: [{ type: 'text', text: JSON.stringify({ error: 'not_found', message: 'Session not found' }) }] }`. Otherwise return messages as JSON text content.
- Description: "Get messages for a session. Returns first and last messages with a skip count for long sessions."

**Tool 4: get_dates**
- No inputSchema (omit the field entirely for no-argument tools)
- Handler: Query DB directly — `db.prepare('SELECT DISTINCT DATE(first_message_at) AS date FROM sessions WHERE first_message_at IS NOT NULL ORDER BY date DESC').all()`, map to `{ dates: rows.map(r => r.date) }`
- Description: "Get all dates that have session data. Useful for discovering which dates to query."

**Response format for all tools:**
```javascript
return { content: [{ type: 'text', text: JSON.stringify(data) }] };
```
