  <action>
**In `src/importer/index.js`:**

1. Import `cleanUserMessage` from `../utils/parse-command-xml.js` (already imported partially — `parseCommandXml` is imported in parser.js, but index.js needs `cleanUserMessage`).

2. Create a helper function `extractMessageContent(msg)` near the top of the file (after imports):
   - If `msg.type` is not `'user'` and not `'assistant'`, return `null`.
   - Call `extractContentText(msg.rawMessage)` (already exported from `../importer/parser.js`) to get raw text.
   - If result is empty/falsy after trim, return `null`.
   - For user messages: pass through `cleanUserMessage(text)` to strip XML tags (slash commands, bash tags, skill expansion tags).
   - For assistant messages: strip XML tags using a simpler approach — assistant messages don't have slash command XML but may have skill tags. Use the same `cleanUserMessage()` which handles all tag types.
   - After cleaning, trim the result. If empty, return `null`.
   - Apply truncation: if `cleaned.length > 1250`, find the last space at or before index 1000 (`cleaned.lastIndexOf(' ', 1000)`), slice there, append `"..."`. If no space found (unlikely), slice at 1000 and append `"..."`.
   - Return the final string.

3. Import `extractContentText` from `./parser.js` (add to existing import).

4. In the `importFile()` function, update the `messagesForDb` mapping (around line 330) to include `content`:
   ```javascript
   const messagesForDb = messages.map(msg => ({
     uuid:           msg.uuid,
     type:           msg.type,
     subtype:        msg.subtype,
     timestamp:      msg.timestamp,
     parent_uuid:    msg.parentUuid,
     git_branch:     msg.gitBranch,
     is_meta:        msg.isMeta ? 1 : 0,
     is_sidechain:   msg.isSidechain ? 1 : 0,
     is_fork_branch: forkData.forkBranchUuids.has(msg.uuid) ? 1 : 0,
     fork_branch_id: forkData.forkBranchMap.get(msg.uuid) ?? null,
     content:        extractMessageContent(msg),
   }));
   ```

5. Also update the agent file import section (around line 547) to include `content: null` in the agent message mapping (agent messages are sidechains, not user/assistant — they don't need content stored, but the field must be present for the db-writer):
   ```javascript

   ```
